# Project-RAZGROM
Проект это Telegram-бот, помогающий студентам нашего факультета готовится к экзаменам. Студенты могут сохранять в чат-бота свои конспекты, получать в том же чате структурированные ответы на вопросы и практиковаться в сдаче экзамена. Проект содержал 5 агентов включая OCR, режим квиза и объяснения.
