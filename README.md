# Project-RAZGROM
Проект помогающий студентам нашего факультета готовится к экзаменам. Проект заключается в том, что студенты могут сохранять в чат бота свои конспекты, получать в том же чате структурированные ответы на вопросы и практиковаться в сдаче экзамена. Проект содержал 5 агентов включая OCR.
